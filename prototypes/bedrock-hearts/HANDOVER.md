# Session 005 Reanimation Table handover

Hearts & Lives **0.3.0** routes Artificial Heart recovery through the placed Reanimation Table (`waveform:reanimation_table`). Hold the heart you want to spend when you interact. The table restores the interacting player's logical balances using the full or half grant. Use the development `/give` fixture to obtain the table. [Download](dist/hearts-and-lives-dev.mcaddon) · [Build and retail test procedures](README.md)

- **Activation.** The first interaction press against the table queues a recovery attempt. At execution, the player must still be eligible and in the same dimension, with the same selected slot and matching heart stack. A Reanimation Table must still occupy the original location. The attempt debits one item and verifies the saved grant. A separate button press can start another attempt when the player has sufficient deficit.
- **State.** A version 2 JSON record lives in a world dynamic property keyed by the opaque player entity ID under the retained behavior pack UUID. A new player starts with 20 half-units for each balance. The v1 migration expands a linked `units` balance into separate fields. Invalid or future records are preserved for inspection. A persisted death latch and tick guard protect the death deduction. The spawn handler enforces elimination.
- **Recovery accounting.** The script verifies the selected stack and debit, then writes the new state synchronously. If the prior record is still present after a failed write, it restores a verified debit. Inventory and world state lack a shared durable transaction, so interruption between the writes can leave them out of sync.
- **Automated evidence.** Strict TypeScript compilation and 36 logic and mocked adapter tests passed. The tests exercise table-only activation, duplicate handling, rechecking a scheduled use, recovery transaction faults, and life-state regressions. Static validation of the behavior pack, resource pack, and nested archives passed. The separate native-cap packs also passed their five mocked tests and archive checks. Retail gameplay and cross-platform delivery require the hardware checks below.
