# Minecraft Bedrock Survival

This repository contains Minecraft Bedrock survival add-on prototypes. The previous Pixel Cutter application was retired.

- Hearts & Lives **0.4.2** ties each player's saved lives to native maximum health. Full and half Artificial Hearts restore capacity at the Reanimation Table. The optional progressive hunger setting defaults off. [Development add-on and gameplay checks](prototypes/bedrock-hearts/README.md)
- The standalone Native Health Probe demonstrated five native hearts through fall death and respawn on Windows. Native hunger still needs retail testing. [Separate diagnostic packs and procedures](prototypes/bedrock-native-caps/HANDOVER.md)
