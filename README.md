# Minecraft Bedrock Survival

This repository contains Minecraft Bedrock survival add-on prototypes. The previous Pixel Cutter application was retired.

- Hearts & Lives provides persistent lives, Artificial Heart crafting, and recovery at the Reanimation Table. [Download and test instructions](prototypes/bedrock-hearts/README.md)
- The native cap probes test whether Bedrock player component groups can set individual health and hunger maxima. [Diagnostic packs and test procedures](prototypes/bedrock-native-caps/HANDOVER.md)
